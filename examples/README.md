# 예시

`ai_flower.txt` 는 AI 에게 "동네 꽃집이 아침을 준비하는 과정을 15문장으로 써라"라고 시켜 받은 글이고, 사람이 손대지 않았습니다. 파일 이름이 `ai_` 로 시작하면 `ai_tell_eval.py` 와 `style_learn.py` 가 AI 글 견본으로 같이 씁니다.

```bash
python ai_tell_judge.py judge examples/ai_flower.txt --rewrite
```

아래는 표본 두 편(직접 쓴 가게 일기 한 편과 공방 이야기 한 편)만 넣고, 문법 층 규칙 파일과 배운 항목이 없는 상태에서 실제로 돌린 출력입니다.

```text
AI 티 판정: A등급 (확실한 의심 0곳, 1,000자당 0.0). 문장 길이와 짜임이 균일한 일과 나열형 문단이고 '한층 더 밝아진다', '본격적으로 시작된다' 같은 부풀린 마무리가 있으나 규칙에 명확히 걸리는 표현은 적다
- (약) [8] "주인은 가게 앞 화분에 물을 주고 밤새 쌓인 먼지를 닦는다." : 거의 모든 문장이 '주인이 ~한다' 식의 비슷한 길이와 짜임으로 이어져 균일한 틀을 이룬다 → 문장 길이와 짜임을 달리하고 구체적인 장면이나 사실을 넣는다
- (약) [7] "은은한 음악이 흐르면 가게 안은 꽃향기로 한층 더 밝아진다." : 사실을 더하지 않고 분위기만 부풀린 상투적 묘사이며 꽃향기로 밝아진다는 표현도 뜻이 흐리다 → 실제로 틀어 두는 음악이나 가게 안 모습을 구체적으로 적거나 문장을 뺀다
- (약) [7] "첫 손님이 들어올 때쯤 꽃집의 하루가 본격적으로 시작된다." : 앞 내용을 되풀이하며 의미를 부풀려 닫는 상투적 마무리 문장이다 → 첫 손님이 무엇을 사 갔는지처럼 구체적인 장면으로 끝낸다
- (약) [6] "예약 주문 내용을 다시 확인해 필요한 꽃을 미리 묶어 둔다." : '묶어 둔다'가 꽃다발을 미리 만든다는 뜻인지 흐려 일을 물건 다루듯 말한 느낌이 있다 → '미리 꽃다발로 만들어 둔다'처럼 일의 내용을 분명히 쓴다

고쳐 쓴 문장
1. (약) 주인은 가게 앞 화분에 물을 주고 밤새 쌓인 먼지를 닦는다.
   → 주인은 가게 앞 화분에 물을 주고 밤새 쌓인 먼지를 닦은 뒤에, 새벽 시장에서 들여온 꽃 상자를 조심스럽게 가게 안으로 옮긴다. (뒤 문장과 이어 씀)
2. (약) 은은한 음악이 흐르면 가게 안은 꽃향기로 한층 더 밝아진다.
   → 가게 안에는 음악을 작게 틀어 두는데, 꽃을 다 꽂고 나면 가게 안에 꽃 냄새가 은은하게 퍼진다.
3. (약) 첫 손님이 들어올 때쯤 꽃집의 하루가 본격적으로 시작된다.
   → 꽃을 다듬어 진열하고 예약 꽃다발까지 만들어 두는 일은 대개 손님이 오기 전에 끝내 둔다. (원문 앞에 더할 문장)
4. (약) 예약 주문 내용을 다시 확인해 필요한 꽃을 미리 묶어 둔다.
   → 예약 주문 내용을 다시 확인해서, 주문받은 꽃다발은 손님이 찾으러 오기 전에 미리 만들어 둔다.

(12.8초, 입력 3,658토큰, 모델 claude-sonnet-5-5)
```

이 상태에서는 의심이 전부 "약"이라 A 등급이 나오고, 돌려보내지 않습니다. 같은 글을 표본 열세 편과 배운 항목 넷을 실은 상태로 돌렸을 때는 "첫 손님이 들어올 때쯤…" 문장이 배운 항목(앞 내용을 일반화한 경구 한 줄로 닫는 꼴)에 걸려 "강"이 되고, 단문이 처음부터 끝까지 같은 길이로 이어지는 곳이 하나 더 "강"으로 잡혀 C 등급으로 돌려보내졌습니다. 표본과 수정 기록이 쌓일수록 같은 글에서 "강"이 늘어나는 것이 정상입니다.

돌려보낼 때 AI 가 받는 글은 이런 모양입니다.

```text
[AI 티 판정] 이번에 쓴 글을 다시 읽어 보니 AI 가 쓴 티가 남아 있습니다. 아래 문장을 그 파일에서 고치세요.
파일: probe.md  등급 C (확실한 의심 2곳)
- "시든 잎은 떼어 내고 상한 꽃은 따로 골라낸다." : 비슷한 길이의 단문이 처음부터 끝까지 이어져 리듬이 균일하다. → 일부 문장을 이어 장문 하나로 만들고 종결을 다양하게 바꾼다.
- "첫 손님이 들어올 때쯤 꽃집의 하루가 본격적으로 시작된다." : 글을 일반화한 경구 한 줄로 닫고, '본격적으로'는 사실을 더하지 않는 부풀림이다. → 첫 손님이 무엇을 샀는지 같은 구체 장면으로 끝내거나 마무리 문장을 뺀다.
```
